# フォローBot

スマホのブラウザだけで動く、コピートレード（フォロー取引）のシミュレーターです。

- 週間ランキング上位のトレーダーを **最大8人同時に** 「雇い」、その人たちの売買を **仮想資金** で追従します（初期設定：8人・資金 $52・倍率 0.25倍）。
- 相手が売ったら同じ割合だけ決済します。
- 人ごとに連敗を数え、決済が **2回連続で損失** になったら、その人を解雇して次の順位の人を雇います（人数・回数は設定で変更可）。
- 画面：残高・損益・最大ドローダウン・勝率、残高の推移グラフ、コピーログ、目標までの進み具合、フォロー中のウォレットのカード。
- 実際のお金は動きません。ウォレットや秘密鍵も不要です。

## 使い方（スマホ）

1. 公開ページを開く（GitHub Pages）。
2. まずはそのまま「開始」を押すと **デモモード**（架空のトレーダー）で動きを確認できます。
3. 本物の取引で試すときは「設定」タブで
   - モードを「実データ」に変更
   - 「フォロー候補」に、ランキングのページをコピーしてそのまま貼り付け（ウォレットアドレスと名前を自動で拾い、順位順に並べます）
     - おすすめ：Solana Tracker の FOMO ランキング（7D）、Kolscan のランキング
     - プロフィールのURLを並べて貼っても読み取れます
   - 保存して「開始」
4. ブラウザの「ホーム画面に追加」でアプリのように使えます。

## 候補の自動収集

「設定」の「候補を自動で集める」を押すと、ランキングをコピペしなくても候補を集めます。

1. DexScreener で、いま値上がりしている Solana のトークン（流動性 $10,000 以上、1時間で+30%か6時間で+80%以上）を最大10銘柄探す
2. それぞれの取引ペアの直近の取引を読み、そのトークンを買った本人と買値を拾う
3. 今の価格が買値の2倍以上になっている銘柄の数が多い人ほど上位にして、最大40人を候補に入れる

集めた候補は「自動-」で始まる名前で候補欄の先頭に入り、手で貼った候補はその下に残ります。もう一度押すと自動の分だけ入れ替わります。

## 過去データで検証

画面中央の「過去データで検証」で期間（6時間〜7日）と1人あたりの件数を選んで「検証する」を押すと、候補の過去の取引を読み込み、今のルール（人数・倍率・連敗で交代）でコピーしていたらどうなったかを数分で再現します。リアルタイムで待たなくても、たくさんの取引で成績を確かめられます。

- 解雇されたあとに補充される人の分まで、上位「人数＋12人」の取引を読み込みます。
- 最後まで持っていた銘柄は、今の価格で評価します。
- SOLの価格は今の価格で計算するので、期間が長いほど誤差が出ます。
- 読み込む取引が多いほど時間がかかり、RPCの回数も増えます（Helius の無料プランがおすすめ）。

## しくみ

- Solana RPC の `getSignaturesForAddress` / `getTransaction` でフォロー先ウォレットの取引を監視し、トークン残高と SOL / USDC / USDT の増減から「買い」「売り」を判定します。
- SOL の価格は Jupiter Price API、保有銘柄の評価額は DexScreener API から取得します。
- 状態はブラウザ（localStorage）に保存されます。

- フォロー先はアドレスで管理します。ランキングを貼り直すと、解雇していない人のうち一番上の人が次に雇われます。

## 制限

- 画面を閉じている間は動きません。開き直すと、止まっていた間の取引を最大25件まとめて反映します。
- 約定価格はトレーダー本人の価格にスリッページを足した概算です。実際に追従すると、遅れの分だけさらに不利になります。
- RPCは空欄なら、登録不要の無料RPC（PublicNode・OnFinality・NodeFlare・Solana公式）を順に試し、403などで断られたら自動で切り替えます。それでも失敗が続くときは Helius の無料プランのURLを設定してください。
