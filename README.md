# フォローBot

スマホのブラウザだけで動く、コピートレード（フォロー取引）のシミュレーターです。

- 週間ランキング上位のトレーダーを上から順に「雇い」、その人の売買を **仮想資金** で追従します（初期設定：資金 $52、倍率 0.25倍）。
- 相手が売ったら同じ割合だけ決済します。
- 決済が **2回連続で損失** になったら、そのトレーダーを解雇して次の候補に交代します（回数は設定で変更可）。
- 実際のお金は動きません。ウォレットや秘密鍵も不要です。

## 使い方（スマホ）

1. 公開ページを開く（GitHub Pages）。
2. まずはそのまま「開始」を押すと **デモモード**（架空のトレーダー）で動きを確認できます。
3. 本物の取引で試すときは「設定」タブで
   - モードを「実データ」に変更
   - 「フォロー候補」に、ランキングのページをコピーしてそのまま貼り付け（ウォレットアドレスと名前を自動で拾い、順位順に並べます）
     - おすすめ：Solana Tracker の FOMO ランキング（7D）、Kolscan のランキング
     - プロフィールのURLを並べて貼っても読み取れます
   - 保存して「開始」
4. ブラウザの「ホーム画面に追加」でアプリのように使えます。

## しくみ

- Solana RPC の `getSignaturesForAddress` / `getTransaction` でフォロー先ウォレットの取引を監視し、トークン残高と SOL / USDC / USDT の増減から「買い」「売り」を判定します。
- SOL の価格は Jupiter Price API、保有銘柄の評価額は DexScreener API から取得します。
- 状態はブラウザ（localStorage）に保存されます。

- フォロー先はアドレスで管理します。ランキングを貼り直すと、解雇していない人のうち一番上の人が次に雇われます。

## 制限

- 画面を閉じている間は動きません。開き直すと、止まっていた間の取引を最大25件まとめて反映します。
- 約定価格はトレーダー本人の価格にスリッページを足した概算です。実際に追従すると、遅れの分だけさらに不利になります。
- RPCは空欄なら、登録不要の無料RPC（PublicNode・OnFinality・NodeFlare・Solana公式）を順に試し、403などで断られたら自動で切り替えます。それでも失敗が続くときは Helius の無料プランのURLを設定してください。
